🛡️

Trần Bộ Nhớ 200MB & Miễn Nhiễm OOM

Thiết lập cờ --max-memory-restart 200M trên PM2 cho toàn bộ chu trình khởi động và tự động cập nhật (/update). Cơ chế đọc log lỗi /logs sử dụng thuật toán đọc ngược byte từ cuối file (OOM-Safe reverse tailing), tiêu thụ chính xác 0 MB RAM phụ trội bất kể dung lượng file log.

🐙

Không Chạy Git Clone Nặng Đĩa

Thay vì dùng git clone tải toàn bộ lịch sử commit gây ngốn RAM và bộ nhớ ổ đĩa hạn hẹp của VPS, hệ thống gọi trực tiếp GitHub REST API tải zipball nén của commit mới nhất. Tự động làm phẳng cây thư mục lồng để Nginx phục vụ ngay lập tức.

⚡

Phân Lập Nền Tảng Thông Minh

Các dự án Frontend nặng (React, Vue, Vite, Next.js) được tự động điều hướng sang Vercel Edge Server để build và host hoàn toàn miễn phí. Máy chủ VPS chỉ đảm nhận Web tĩnh thuần và Node.js Backend, giữ tải CPU máy chủ luôn dưới 5%.

🔒

Bảo Mật Zero-Leakage & Google OAuth 2.0

Phân quyền 2 lớp độc lập: Telegram ID Whitelist cho các lệnh chat, và Google OAuth 2.0 kèm Whitelist Email cho Web Dashboard. Lệnh shell /sh bị cô lập theo danh mục whitelist nghiêm ngặt, chặn hoàn toàn command injection.
